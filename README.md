# Pizza Sales Analysis Using SQL

##  Project Overview

This project analyzes pizza sales data using **SQL** to uncover meaningful insights into order volume, revenue, customer ordering patterns, pizza popularity, and product performance.

The analysis was designed to answer key business questions such as which pizzas generate the most revenue, which sizes and categories are most popular, when customers place the most orders, and how revenue changes over time.

##  Business Objective

The primary objective of this project is to transform raw pizza transaction data into actionable business insights that can help improve:

* Product and menu strategy
* Inventory planning
* Staffing during peak hours
* Promotional campaigns
* Revenue optimization
* Overall sales performance

##  Dataset

The project uses four relational tables:

* **orders** – Contains order date and time information
* **order_details** – Contains pizza quantities associated with each order
* **pizzas** – Contains pizza size and price information
* **pizza_types** – Contains pizza names, categories, and ingredients

These tables were connected using SQL joins to perform the analysis.

##  Analysis Performed

### Basic Analysis

* Total number of orders
* Total revenue generated
* Highest-priced pizza
* Most frequently ordered pizza size
* Top 5 most ordered pizza types

### Intermediate Analysis

* Quantity of pizzas ordered by category
* Order distribution by hour
* Category-wise pizza distribution
* Average pizzas ordered per day
* Top 3 pizza types by revenue

### Advanced Analysis

* Revenue contribution percentage by pizza type
* Cumulative revenue over time
* Top 3 revenue-generating pizzas within each category

## Business Recommendations

Based on the analysis, businesses can:

1. Prioritize high-demand pizza types and sizes in inventory planning.
2. Align staffing and kitchen capacity with peak ordering hours.
3. Promote high-revenue pizza products through targeted offers and combos.
4. Review the performance of different pizza categories to optimize the product mix.
5. Use revenue and order trends to support pricing and promotional decisions.

##  Project Outcome

This project demonstrates how **SQL can be used to move from raw transactional data to business-focused insights** through data aggregation, table joins, time-based analysis, revenue analysis, and advanced window functions.

It showcases practical SQL skills relevant to **Data Analyst and Business Analyst roles**.
